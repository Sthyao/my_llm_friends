# 想法簿历史库实验

历史库回答「当时具体说过什么」。实验直接从现有 SQLite 的对话事件找原话，因此一次对话可以被检索，即使角色当时一句话也没说，或者没有把它提炼成私有记忆。

| 当轮可用资料 | 范围 | 负责的事 |
| --- | --- | --- |
| 短期窗口 | 当前会话最近 8 条可见消息 | 接住眼下的话题和发言关系 |
| 角色私有记忆 | 各角色自己的约定和界限 | 记得需要延续或兑现的事 |
| 对话历史 | 当前会话窗口外的原话，以及允许跨会话检索的会话 | 找回具体往事、对照以前的说法 |

## 从检索到角色行动

1. **决定是否查找。** CLI 默认使用 `auto`。带有回顾信号的用户提问直接触发一轮查找。人格原文也可写「当用户再次提到一件聊过的具体事情时，先查当时怎么说」，编译器把这条指令放入对应技能的 `archive` 字段。当轮候选带上原话中的触发片段，才可以提议查找。控场最多执行一次，结果只交还给提出查找的角色。普通聊天没有触发时继续走短期和私有记忆。也可用 `--history lookup` 显式触发，或用 `--history off` 跳过本轮新检索。
2. **先查原话，再补齐轮次。** 在可读事件里按英文词和中文 2–4 字片段打分，同一轮的发言可以跟着锚点一起返回。取最多 6 个命中轮次和 12 条消息，当前短期窗口内已提供的消息跳过。返回带 ID、原作者和会话名的片段，按全局消息 ID 排序。这个小规模版本用 SQLite 扫描候选，时间先后取消息插入顺序。
3. **按本轮问题总结。** 只命中一轮时直接用原话。跨多个轮次时用 DeepSeek Flash 做一次带出处的归纳，最多 4 个要点。程序只接受引用了已载入消息 ID 的要点。摘要在本轮使用，进展、矛盾和不确定性可以同时保留。原话与摘要都进入行动阶段。角色仍可决定说或听。
4. **带引用发表。** 角色使用历史回答时，返回原始消息 ID。程序校验结构化出处及正文里显式标出的 `[M…]`，把真实引用写入 `archive_sources`。查询和总结结果出现在实验输出里。角色可以按既有规则用本轮用户原话提议长期记忆。

## 共享与回退

会话默认仅供本会话检索。开启共享后该会话的原话可以出现在其他会话的历史查询里。已引用其他会话资料的自动回复保留来源关联，后续检索只从原始事件取材。撤回某条源消息时，一并撤回直接引用它的历史回复，并保留提问。关闭共享时，已经依赖该会话的历史回复会从后续短期窗口中隐藏。提交前会在同一个 SQLite 事务里重新检查所有读取来源仍可用。

这期追踪直接引用。普通回复经由短期上下文间接复述旧资料的传递性出处属于下一层设计。摘要和回复的语义质量仍取决于模型，程序可以核验消息归属和 ID。本轮摘要随本轮使用，不跨轮缓存。

## 复现

```sh
.venv/bin/python -m unittest exp.test_archive -v
.venv/bin/python -m exp.evaluate_archive --repeats 1 --output exp/results/archive-latest.json
```

实测入口通过虚构数据建立对照。主问题跨会话询问观点变化，另外测关闭历史库、撤销共享、回退原话、同会话滚出窗口的消息，以及由人格主动发起的查询。报告记录检索命中、摘要、最终出处、回复和调用用量。

手动跑时可用实验库默认角色，也可用 `publish keeper 人格.md` 发布包含主动翻查指令的新人格。

```sh
.venv/bin/python -m exp init
.venv/bin/python -m exp say cinema '我最初想保留旧电影院的整座建筑。'
.venv/bin/python -m exp say cinema '后来我改主意了，旧电影院只保留入口和放映厅就好。'
.venv/bin/python -m exp archive-sharing cinema on
.venv/bin/python -m exp say today '@拾荒者 翻一下之前的聊天，我对旧电影院的看法怎么变过？' --history lookup
```

将共享改为 `off` 或回退旧会话里某条用户原话，再发同样的问题，可以对照资料如何消失。

## 实测

两组 DeepSeek Flash 对照实验各通过 15 项检查。两组都在短期窗口为空、角色没有私有记忆时查回了两条旧原话，解释了观点改变的原因。关掉后一个会话的共享或撤回那条原话后，只引用仍可用的早期观点。两次从自然语言编译的人格技能都主动查到了旧话。

跨会话主场景每轮调用 3 次模型，中位耗时 3.04 秒。只命中同会话一轮原话的场景每轮调用 2 次。报告记录了关闭检索对照的模型原始措辞。最终代码对关闭检索且缺少可答前情的回顾问题，直接说明本轮未检索并请求线索。
