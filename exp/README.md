# 人格 Harness 实验

这个子项目用刺头和拾荒者验证，角色的人格指令与各自的经历能否共同改变召回、发言和沉默。模型统一使用 DeepSeek 官方接口的 `deepseek-flash`。人格编译开启低强度 thinking，行动判断、记忆提议和表达关闭 thinking。API 密钥可通过环境变量 `DEEPSEEK_API_KEY`、`exp/.env` 或仓库根目录的 `.env` 提供。实验会把输入发给 DeepSeek。

[历史库设计与测试](archive-design.md)覆盖从对话原话检索、按问题总结、带出处地参与角色决策。

## 跑对照

在仓库根目录使用现有 Python 环境。也可以用 Python 3.11 以上单独建环境，从 [requirements.txt](requirements.txt) 安装实验依赖。

```sh
.venv/bin/python -m exp.evaluate --repeats 3 --output exp/results/latest.json
```

每组使用一份临时 SQLite，分别编译两个人格，再从虚构对话中实际写入约定和界限。从相同快照配对比较完整 Harness、停用行为技能和回退约定，另测无记忆与有同等记忆的单轮 Prompt。主对照固定输入「写完了」，再用新输入测试点名和同会话历史、无关进展和实际兑现约定。报告记录模型用量、调用耗时、动作和引用。

## 手动复现

```sh
.venv/bin/python -m exp init
.venv/bin/python -m exp say feedback '@刺头 关于旧电影院的文章我想自己写，等我问你再给意见。'
.venv/bin/python -m exp say draft '@拾荒者 我在写一篇关于旧电影院的文章，写完给你看。'
.venv/bin/python -m exp say later '写完了'
.venv/bin/python -m exp inspect keeper
```

改写人格时可用 `python -m exp publish keeper 人格.txt`。每次发布保存原文、编译结果和版本。命令行显示本轮各角色实际读取的短期上下文、私有记忆和阶段指令。通过 `say 新会话 '写完了' --disable keeper` 可停用拾荒者的行为技能并保留表达风格。用 `rewind 用户消息ID` 可撤回实验消息。手动命令默认使用 `exp/.data/chat.sqlite3`，可用 `--db` 选用另一份实验库。

## 运行边界

- 两个角色各看当前会话最近八条可见消息。角色私有记忆只取技能获准读取的最近四项未结记录。历史库在触发时补充经过共享检查的旧对话。
- 发言前每个候选提出「说」或「听」，并可提交一项有原文出处的记忆变更。控场最多发布一条发言，有明确记忆出处的提议优先。记忆写入与消息在同一事务里落库。
- 有旧记忆候选时先执行召回核对。模型判断是否在讲同一件事，指出本轮原话中的关联片段，并单独判断约定是否已兑现。程序先检查原话和记忆归属，再将匹配的记录交给行动阶段。
- 回退按当前会话的消息后缀执行，并撤销关联的私有记忆及直接引用已撤回原话的跨会话发言。解析和存储均使用实验数据。
- 没有可引用前情且对话窗口为空时，生成后的回复会再检查一次。凭空预设旧事的候选发言留在实验记录里，当轮只保存用户消息和有效的记忆变更。

## 实验迭代

每次迭代都用同一批虚构场景做三组对照。

| 实现 | 观察 |
| --- | --- |
| 合并召回、行动和写入判断 | 一组在聊晚饭时把文章约定误标为行动依据。 |
| 增加原话关联字段 | 三组都把「写完」误判为已经履约，而且漏标实际用过的依据。 |
| 拆出召回和兑现核对 | 三组通过当时的结构检查。人工复查发现两次在回退后用疑问句暗示旧约定，由此加入正文检查。 |
| 检查缺少前情的候选回复 | 三组回退后的回复都通过检查。其中一次刺头把「等我问」延用到已被点名提问的一轮，由此明确当轮邀请的优先级。 |
| 明确当轮邀请的优先级 | 最终三组各 16 项检查全部通过。正文核对拦下两次回退后凭空暗示约定的候选发言。 |

最终三组里，拾荒者都能在未发言时记录约定，并在新会话用它接住「写完了」。刺头引用自己的界限选择等待，收到点名邀请后回应。停用拾荒者的行为技能时，旧约定仍在数据库里，两次自然接话、一次保持沉默，都没有调用约定。

给单轮 Prompt 同等记忆，它三次也都认出了那篇文章。完整 Harness 的主场景每轮调用 5 次，中位耗时 3.87 秒。带同等记忆的单轮 Prompt 每轮调用 1 次，中位耗时 1.20 秒。这组实验验证了人格能参与记忆的形成、使用和撤销，以及发言前的选择。它只覆盖两个角色、两种记忆和一组固定虚构场景，单句体验仍需更多场景才能比较。
