# 想法簿 V2 · 人格如何参与一次对话

这是一份设计草案。第一期用刺头和拾荒者验证一件事：同一个人设、同一句输入，先前的共同经历能否改变角色的选择，甚至让他这次只听。

## 作者写什么

在现有「人格模板」里继续写自然语言。以下两段可以直接作为样例输入。

**拾荒者**

你特别容易记住朋友说到一半、留待下次的事。对方自己提起进展时，你喜欢接住那个线头。记得清楚才提旧事，拿不准就给对方讲下去的空间。一句话能接住，就停在那里。

**刺头**

你关心一个人究竟是在做选择，还是在重复一个听起来有道理的理由。朋友要你拿主意时，给自己的判断和一个具体理由。朋友说想先自己试试，你就让他试。等他明确请你看，你再认真挑一个最值得讨论的地方。

保存时解析一次，把作者原文拆成可独立启用的行为指令。语义拆分可以用模型；指令结构、可选动作、可读数据和写入权限由程序校验。相同的已发布版本在对话中直接加载。编辑器可展开查看「这句设定会在什么时候生效」，作者可以纠正归类；普通编辑无需填写阶段或写 YAML。没有明确行为含义的描述可以仅进入表达阶段，或留作背景。保留原文、编译结果和版本，编译失败时继续使用上一个有效版本。

例如拾荒者的头两句可编成一个技能。下表是这一个技能的运行契约示例。

| 字段 | 示例 |
| --- | --- |
| 名称与来源 | 接续未完的约定。来源为作者原文的前两句 |
| 可激活情形 | 当前谈话对象有未结约定，并且对方提起相关进展 |
| 注意与召回 | 查看这个人最近的未结约定；按需读取约定的原话 |
| 行动偏好 | 内容对得上时接对方这一句；存在多个可能指代时可以轻问或等一等 |
| 记忆写入 | 对方明确提出约定时可以提议登记；实际履约后可以提议完成。各自附上对应消息 |
| 表达 | 对方只报了进展时，一句就够 |

一个技能可以跨多个阶段，一个阶段也可以命中多个技能。运行时按阶段取对应条目，传给当次决策或表达调用。选择检索范围、检查证据、限制动作和提交状态由代码执行。纯表达指令只能改写措辞。

## 一轮如何运行

| 阶段 | 人格怎样介入 | 运行时产物 |
| --- | --- | --- |
| 看到消息 | 先结合收件人、回复关系和每个角色少量未结事项筛选候选，再按角色的注意偏好读取本轮片段 | 各候选看到的消息 ID、可能相关的未结事项 |
| 回忆 | 按激活技能检索有权读取的消息或记忆，返回原话和来源；允许找不到 | 角色可使用的证据集合 |
| 选择行动 | 候选结合短期状态、证据和人格指令，提出接用户、接群友、只听或再查一条原话；首版最多补查一次 | 提议的动作、对象、所接消息、相关证据 |
| 控场和表达 | 控场处理点名、停止、发言数与重复。获准发言的角色才加载表达指令；模型沿用已选的动作和对象 | 可见回复和现有引用。停听也能结束一轮 |
| 记住或修正 | 处理本轮实际看到的事和已经发生的动作。没抢到话筒或选择沉默的角色，也可据原话提出记忆变更 | 按角色保存的新增、修订、完成或撤销记录 |

表里的阶段是职责划分。第一期可以把注意、选取相关候选证据和提出行动合在一次结构化决策里，只有缺原话时才补读。明确点名直接进入受邀角色的决策；已有 V1 手动邀请仍回复指定对象。用户明确要求安静时优先尊重。角色提议不能自行启用联网工具、扩大记忆可见范围或绕开发言上限。

## 什么随时间改变

- **短期状态按角色和会话保存。** 记录当前在接谁的话、本轮已看到哪些消息、刚才是否已问过同一个问题。随话题结束清掉或过期。
- **长期记忆按角色保存。** 自己表过的态、和谁约过什么、对一次互动的理解分别记录。约定带对象、状态和原话；个人理解标为推测，可被后续经历修正。未结事项按谈话对象取少量摘要，因此「写完了」也有机会接回「下次给你看」。
- **公共消息和用户观察继续沿用 V1 的出处。** 角色可在既有共享设置范围内读取；私有解释只归形成它的朋友。影子自我继续使用用户原话和有来源的观察。两只 bot 即使用同一人格模板，也有各自的经历。
- **作者指令有独立版本。** 日常经历可以改变一个判断、建立或解除一项约定。直接修改作者设定由人格编辑入口完成。运行记录带人格版本、激活指令、动作和证据 ID，方便做回放对照。

## 接入现有工程

在人格配置旁保存版本化指令，数据库中用户已编辑的原文优先。试点角色显式切换到新路径，其他角色可继续沿用 V1。将角色决策插入主聊和自动侧聊的选人之前；保留现有回复格式修复、引用校验、模型配置和监控。把私有经历的写入从「必须成功发表一条回复」扩展到「有一条角色确实看到的来源事件」。既有发言笔记沿用原作者和来源。

每笔状态变更记录角色、来源消息、触发轮次及依赖的旧记忆。提交前核对轮次仍有效，重复执行同一决定只提交一次。回退时撤销由被删事件引起的变更，包括跨会话派生的私有结论；由其他有效事件支持的记录保留或重算。新表随备份导入导出，旧备份缺少新表时从空状态启动。

## 用同一句话验收

在隔离会话里固定模型、人格版本和最后一句「写完了」，对比以下条件。观察行动、目标消息和来源，不要求模型逐字复现台词。

| 前情或改动 | 应观察到的结果 |
| --- | --- |
| 你对拾荒者说过「写完给你看」 | 他能接回这项约定，并指到旧消息；仅仅写完还不足以把「给你看」标为完成 |
| 你还对刺头说过「这次我先自己试，等我问你再给意见」 | 他可以听着；你后来明确邀请时，他才给具体判断 |
| 回退建立约定的消息，再发「写完了」 | 拾荒者仍可自然回应，但不能声称你答应给他看；已失效的约定不能参与选人 |
| 保留记忆，只停用拾荒者的「接续未完的约定」，保留表达指令 | 该技能不再触发定向召回或提交行动提议；从其他途径自然聊到同一话题仍然合理 |

同一组条件重复几次，比较 V1、完整 V2、停用行为技能的 V2。先检查引用、隔离和回退是否正确，再盲看角色的行动是否合乎前情，同时记录首条回复延迟和每轮模型调用数。这决定是否推广到其他人格。
